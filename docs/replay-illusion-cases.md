# Replay Analyzer: Illusion Cases

The analyzer does not model Illusion yet. These are real games with Zoroark or Zorua on a
team, kept as test cases for when it does.

## What goes wrong today

- While disguised, Zoroark's damage and kills are credited to the Pokémon it is impersonating.
- Hits it takes land on that Pokémon too.
- When a hit KOs the disguise, the log reads `-damage` (the disguise, to 0), `replace`,
  `-end Illusion`, `faint` (Zoroark). Zoroark then faints with no killer, and the
  impersonated Pokémon is left at 0 HP.

## How this list is kept

`src/tests/replay-sweep.ts` adds every Illusion game it sees, saves the log to the gitignored
`src/modules/replay-analyzer/__fixtures__/illusion/`, and rewrites the table below. Rows whose
log is missing on this machine are kept as they are; the log can be fetched again from the link.

- **Breaks**: how many times the disguise visibly broke (`|replace|`). 0 means it never broke,
  or Zoroark never came in disguised; the log alone can't tell which.
- **KO'd while disguised**: turns where the breaking hit was also the KO.
